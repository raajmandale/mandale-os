M-OS Visual Assets v0
=====================

This package contains professional repo visuals for the locked M-OS v0 baseline.

Files
-----
svg/mos_architecture.svg
svg/mos_execution_flow.svg
svg/mos_pattern_graph.svg
svg/mos_timeline.svg
html/mos_repo_visuals_showcase.html

Recommended usage
-----------------
1. Put SVGs into your repo:
   docs/assets/svg/

2. Put the HTML showcase into:
   docs/showcase.html

3. In README.md use:
   - mos_architecture.svg
   - mos_pattern_graph.svg

4. In docs/architecture.md use:
   - mos_execution_flow.svg
   - mos_timeline.svg

These files are static and can be opened directly in a browser.
